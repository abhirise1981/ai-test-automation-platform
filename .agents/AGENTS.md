# Project-Scoped Rules

## Git Repository & Push Rules
- Always push code changes to the GitHub repository: `https://github.com/abhirise1981/ai-test-automation-platform` (`github` remote, `main` branch).
- Ensure all CI/CD workflows under `.github/workflows/` are triggered on push.

## User Communication & Answer Style Rules
- **CRITICAL:** Always keep responses **extremely short, concise, and straight to the point**.
- Avoid long stories, lengthy paragraphs, or excessive text.
- Use 1–3 bullet points or short, exact code snippets only.
- Focus strictly on the exact interview-ready answer to prevent confusion and distraction.
